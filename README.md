# About the Project
This project implements a Mashup Generator that:

- Downloads multiple songs of a given singer from YouTube
- Converts videos to audio
- Cuts the first Y seconds from each track
- Merges them into a single mashup
- It is available in:

Command Line Program
Web Application (email delivery in ZIP)
CLI Usage
```
python 102303560.py "<SingerName>" <NumberOfVideos> <AudioDuration> <OutputFileName>
```
Example:

```
python 102303560.py "Sharry Maan" 20 30 mashup.mp3
```
